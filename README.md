# Parlons

PWA (installable sur iPhone) pour apprendre l'anglais : leçons de grammaire expliquées en français,
vocabulaire, verbes irréguliers et conjugaison, oral (écoute, répétition, traduction à voix haute, dictée),
le tout révisé par répétition espacée. Les réponses se tapent toujours au clavier, sans QCM.

Aucune dépendance, aucun build : HTML/CSS/JS natifs, progression enregistrée sur l'appareil.

## Lancer en local

```sh
npm start          # sert le dossier sur http://localhost:8080
npm test           # tests de la logique et du contenu (node --test)
```

## Installer sur iPhone

Ouvrir l'URL du site dans Safari → bouton Partager → « Sur l'écran d'accueil ».
